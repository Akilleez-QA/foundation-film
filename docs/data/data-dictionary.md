The software classification is a self-assessed analog (Class E, not safety-critical); no NASA authority, independent verification and validation, or hazard analysis is asserted. The document describes the implementation inspected at the baseline commit.

Generated parts: the [tool catalog](../guides/reference/tool-catalog.md) (every input and result field, from `foundation_film_bridge/schemas.py`) and the [defaults table](defaults.md) (from the module constants). Both were generated by the documentation lane's generator, an adapted copy of foundation-robotics `tools/gen_docs.py`, which is not in this repository. The rest of this page is written by hand and checked against the code at the baseline commit.

Not applicable: channelization, rate-group, raw or calibrated sensor, telemetry, data-recorder and partitioning data. The software has no hardware or telemetry interface.

## 1. Tools

| Name | Purpose | Required parameters | Result | Restrictions | Source |
|---|---|---|---|---|---|
| `cinematic_gate` | Judge per-segment shot measures | `shots`; `bands` or `rules` | verdict, rules and their source, per-segment measures and checks, failing segments | 1 to 400 shots in time order without overlap, same metric names in every shot (1 to 32); up to 32 rules, 64 segments; default rules need `sharp`, `black`, `subject_motion`, `luma` | `foundation_film/cinema.py` |
| `reference_bands` | Measure reference bands | `shots` | bands per metric, moving share, duration band, shot count, total | as for shots above | `foundation_film/cinema.py` |
| `audio_gate` | Judge the mix against the contract | all of `integrated_lufs`, `true_peak_dbtp`, `voice_over_bed_db`, `cuts`, `cuts_with_hit`, `heard`, `line_wer` (each may be `null`) | verdict, checks, effective contract, overrides, heard summary, WER summary | up to 100000 cuts, 128 labels, 512 lines; `cuts_with_hit` not above `cuts` | `foundation_film/audio.py` |
| `drift_verdict` | Judge control fidelity per frame | `frames.edge_f1` | verdict, first failing frame, per-metric summary, worst frame | 1 to 2048 frames; all series the same length; `depth_error` and `identity_similarity` need caller thresholds | `foundation_film/drift.py` |
| `cue_vocabulary_check` | Check the shared cue vocabulary | `provided`, `lanes` | verdict, missing ids, broken aliases, per-lane, order and gap results | up to 1024 provided ids, 512 aliases, 64 lanes of 256 references, 64 orders, 64 gaps; an alias may not shadow a provided id | `foundation_film/cues.py` |
| `look_gate` | Rejection alarm for the look | `frames` | verdict, per-frame checks, failing frames, thresholds and their sources | 1 to 128 frames with unique ids; all eight metrics present (each may be `null`) | `foundation_film/look.py` |

## 2. Data elements and conventions

| Name | Type | Units | Range / limits | Default | Meaning | Defined in |
|---|---|---|---|---|---|---|
| Measure | integer | milli-units (value x 1000) | -10^12 to 10^12 | — | Any shot metric, rule target or level | `foundation_film/measures.py` `MEASURE_LIMIT` |
| Time | integer | ms | 0 to 86400000 (24 h) | — | Shot, segment and marker times | `measures.py` `MS_LIMIT` |
| Share, WER | integer | per-mille | 0 to 1000 (line WER up to 10000) | — | Fractions such as moving share, cut-hit share, word error rate | `measures.py` `permille`; `audio.py` |
| Identifier | string | — | `^[A-Za-z0-9][A-Za-z0-9:_.\-]{0,63}$` | — | Segment, lane, line, marker, frame ids | `measures.py` `ID` |
| Metric name | string | — | `^[a-z][a-z0-9_]{0,31}$`; not `moving_share` or `duration_ms` in shots | — | Shot metric keys | `measures.py` `METRIC` |
| Camera | string | — | `static`, `pan`, `tilt`, `push/pull` | — | Camera movement class of a shot | `cinema.py` `CAMERAS` |
| Audio label | string | — | printable ASCII, 1 to 96 characters; compared case-insensitively | — | AudioSet class names | `audio.py` `LABEL` |
| Rounding | — | — | — | — | Integer division rounds half away from zero (`div_round`); the producer rounds half up in decimal (`milli`) | `measures.py`, `filmstats.py` |
| Check | object | — | `status` `pass`, `fail` or `not_measured` | — | One threshold test | `measures.py` `check` |
| Verdict | string | — | `thresholds_met`, `thresholds_not_met`, `not_scored` | — | Combined outcome (REQ-FILM-019) | `measures.py` `verdict` |

## 3. Records and files

| Record / file | Format | Schema | Producer | Consumer | Retention |
|---|---|---|---|---|---|
| `SOURCE-MANIFEST.json` | JSON | `foundation-film-source-manifest/1`: `version`, `files` (path → SHA-256) | `tools/build_manifest.py` | host adapter, tests, CI | in git |
| Shots JSON | JSON on stdout | `{"shots": [...]}` matching the `reference_bands` input schema | `python -B -m foundation_film.filmstats` | caller, then `reference_bands` or `cinematic_gate` | not stored by this repository |
| Tool receipt | JSON on stdout | per-tool `outputSchema` | `tools.run` | host | not stored by this repository |

## 5. Configuration keys

| Key | Type | Default | Effect | Defined in |
|---|---|---|---|---|
| `FOUNDATION_FILM_PLAYBOOK` (environment) | string | `docs/PLAYBOOK-film.md` | Citation location text in Evidence; never opened | `foundation_film/tools.py` |
| `FOUNDATION_FILM_PRODUCERS` (environment) | string | `tools/film/` (a trailing `/` is added if missing) | Producer-script location text in Evidence; never opened | `foundation_film/tools.py` |
| `--fps` (producer CLI) | float | 8.0 | Target sampling rate; the actual step is the native rate divided by a whole number | `foundation_film/filmstats.py` |
| `--width` (producer CLI) | integer | 640 | Width frames are resized to; at least 6 | `foundation_film/filmstats.py` |

Both environment variables are read once, when `foundation_film.tools` is imported. `tests/test_gaps.py::GapFilmTests.test_gap_film_09_environment_changes_evidence_citations` covers both (REQ-FILM-029).
